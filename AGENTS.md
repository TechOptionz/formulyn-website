# Git Workflow & Commit Rules

- **Explicit Authorization Only**: Never run `git commit` or `git push` automatically. Only execute git commits/pushes when explicitly instructed by the user.
- **Branch Confirmation**: Always confirm the target Git branch with the user prior to performing any commit or push operations.
